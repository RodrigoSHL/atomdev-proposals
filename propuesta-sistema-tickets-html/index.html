RESUMEN DE LA SOLUCIÓN

Una base común para crecer por etapas.

La plataforma comienza con ServiuPRO-Pagos como primer proyecto, manteniendo una estructura preparada para incorporar nuevos proyectos progresivamente.

Se propone desarrollar una nueva plataforma web para centralizar el registro y seguimiento de soportes e incidencias. La solución será independiente del sistema legacy actual y estará preparada para organizar distintos proyectos o sistemas internos desde un mismo lugar.

ALTERNATIVAS DE IMPLEMENTACIÓN

Tres niveles para decidir cuánto autonomía necesita el Servicio.

Todos parten de la misma base operativa. La diferencia está en la capacidad de configuración, control y crecimiento que queda habilitada.

PAQUETE 01

MVP Base

180horas

Alcance mínimo necesario para comenzar a gestionar incidencias mediante una plataforma centralizada.

  • Login centralizado y cuatro perfiles
  • Cuatro bandejas de trabajo
  • Formulario basado en la planilla entregada
  • ServiuPRO-Pagos y sus tipos precargados
  • Mantenedor para crear y editar proyectos
  • Responsables, estados, fechas y SLA básico
  • Archivos adjuntos y notificaciones por estado
  • Filtros básicos y exportación a Excel
  • Pruebas funcionales y despliegue
ConsideraciónLos tipos de incidencia estarán precargados para ServiuPRO-Pagos y no podrán ser creados ni administrados directamente por el cliente.

PAQUETE 02

MVP Configurable

220horas

La alternativa recomendada para entregar autonomía al Servicio en la incorporación de nuevos proyectos y tipos de incidencia.

  • Todo el alcance del MVP Base

PAQUETE 03

Plataforma Completa

260horas

Alternativa orientada a fortalecer el control de gestión, los indicadores y la trazabilidad histórica.

  • Todo el alcance del MVP Configurable
  • Dashboard operativo
  • Indicadores por proyecto, estado y tipo
  • Solicitudes abiertas, cerradas y vencidas
  • Cumplimiento de SLA y tiempos promedio
  • Histórico de cambios de estado
  • Usuario, fecha, hora, estado anterior y nuevo
  • Historial de reasignaciones
  • Reportería comparativa entre proyectos
  • Mayor documentación y estabilización
ConsideraciónPrioriza la reportería y trazabilidad avanzada como una segunda capa de madurez de la plataforma.

ALCANCE Y LÍMITES

Consideraciones para tomar la decisión con claridad.

Estas condiciones ayudan a mantener el alcance controlado y las expectativas alineadas.

Incluido en la definición

  • Un único flujo de atención.
  • Cuatro bandejas y cuatro perfiles de usuario.
  • Notificaciones únicamente ante cambios de estado.
  • Adjuntos cargados y descargados desde la solicitud.
  • Formulario basado en los campos definidos en la planilla entregada.

Fuera del alcance base

  • No se considera integración automática con el sistema legacy.
  • No se considera migración masiva de datos históricos.
  • No se consideran integraciones con plataformas externas.
  • Las funcionalidades no expresadas en el paquete seleccionado se evaluarán como mejoras posteriores.
